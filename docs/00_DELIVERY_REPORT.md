## 결과물

- GitHub 보관·Codex/Claude Code 설치용 저장소와 스킬 패키지
- ChatGPT 프로젝트 지침·지식 파일·단일 대화 시작 자료·미등록 플러그인 구성

양쪽은 같은 core와 VERSION에서 만들어져요. 설치·배포·갱신·평가 입력의 불일치를 막는 검사와 수정 내용을 `docs/06_FIX_REPORT.md`에 정리했어요.

## 이번에 보존한 것

원문 Master v1.0 전체 파일은 변경하지 않았어요. 28개 규칙의 내용·조건·출처, 주요 GOLD 12개, 추가 GOLD 표시 8개, 기존 Synthetic 20개, 15개 Hard Fail, 100점/90점 기준은 유지했어요. 규칙 파일의 릴리스 버전 필드는 제거하고 스키마 버전을 구분했으며 실행 버전은 VERSION에서 생성해요. 원문 전체는 배포 ZIP에 넣지 않았어요.

## 검증 상태

Linux 임시 폴더에서 정적·출처 검사, 설치 검사, 오류 경로·변조·업데이트·압축 재생성 검사를 수행했어요. 정확한 항목과 결과는 저장소 패키지의 `verification/` 기록을 확인해요. 검사 수는 파일과 실행 코드의 검사 수이지 문구 품질 점수가 아니에요.

**독립 에이전트 실행 0회, 실제 Codex/Claude/새 ChatGPT에서의 라이팅 시험 0회예요.** 현재 환경에서 실행기와 호출 가능한 연결을 확보하지 못했어요. 원문을 본 같은 어시스턴트의 재검토와 모의 데이터 기반 기술 검사만 수행했어요. 역할별 독립 검토 입력을 준비하는 스크립트는 포함했으나 준비와 실행을 구분해요.

## 시작

ChatGPT는 `chatgpt/00_START_HERE.md`, 에이전트 설치는 `docs/03_INSTALL_AGENTS.md`를 읽어요. 설치는 기본 dry-run이며 --apply 전에는 사용자 환경에 복사하지 않아요. 이전 프로젝트 지침·지식 파일은 자동으로 바뀌지 않아요.

GitHub 게시, 사용자 컴퓨터 설치, 계정 설정, 플러그인 공개 등록은 수행하지 않았어요. 공개 전 원문에서 추출한 사례와 소유권을 검토하세요.
