# CHIHUN UX Writing · ChatGPT 시작 안내

버전 0.1.1 · 첫 사용·검토용 초안이에요. 계정에 자동 설치된 것이 아니에요.

## 가장 간단한 설정

**1. 라이팅 전용 프로젝트를 만들어요.**

**2. `PROJECT_INSTRUCTIONS.md`의 내용을 프로젝트 지침에 붙여 넣어요.**

**3. `CHIHUN_KNOWLEDGE_0.1.1.md`를 프로젝트에 파일로 추가해요.**

이후 그 프로젝트에서 실제 문구와 현재 상태·제품 조건을 전달해요.

> 아래 문구를 CHIHUN 기준으로 워싱해 주세요. 적절한 문구는 유지하고 수정안과 중요한 이유만 보여주세요.

‘수정안만 주세요’, ‘문구와 UI 문제를 나눠서 피드백해 주세요’, ‘제목·본문·버튼을 작성해 주세요’처럼 요청할 수 있어요. 상세 예시는 `REQUEST_EXAMPLES.md`에 있어요.

## 프로젝트를 사용하지 않는 경우

`SINGLE_CHAT_STARTER.md`를 새 대화에 붙여 넣고 실제 문구를 이어서 제공할 수 있어요. 한 대화용 시작 자료이고 다른 대화까지 자동 유지되는 설정은 아니에요.

## 들어 있는 자료

| 파일 | 역할 |
|---|---|
| PROJECT_INSTRUCTIONS.md | 프로젝트에 붙여 넣는 실행 지침 |
| CHIHUN_KNOWLEDGE_0.1.1.md | 첨부할 규칙·원문 선호·검수 기준 |
| SINGLE_CHAT_STARTER.md | 단일 대화에 지침과 기준을 함께 제공하는 시작 자료 |
| REQUEST_EXAMPLES.md | 실제 요청 문장 예시 |

별도 `plugin/`이 함께 제공된 배포본에는 스킬 플러그인 초안도 있어요. 프로젝트 설정이 플러그인 설치를 요구하지는 않아요. 플러그인 공개 등록·계정 설치·새 대화 호출은 아직 검증하지 않았어요.

## 주의할 점

첫 지원 범위는 인증/KYC 안내, 결제·구독 상태와 조건, 챌린지 현재 상태·진행이에요. 원문 전체를 모든 도메인에 완전히 이식한 최종판은 아니에요.

기준에 들어 있는 금액·날짜·정책·기관은 예시예요. 실제 작업에는 실제 사실을 제공해요. 파일을 읽지 못했다고 하면 먼저 첨부·버전을 확인해요.

프로젝트 설정 경로의 공식 근거: `https://help.openai.com/en/articles/10169521-using-projects-in-chatgpt` (2026-09-18 확인). 계정·워크스페이스 설정에 따라 기능이 달라질 수 있어요.

## 이전 버전에서 갱신

프로젝트 지침을 현재 `PROJECT_INSTRUCTIONS.md`로 교체하고, 기존 CHIHUN_KNOWLEDGE 파일을 제거한 뒤 `CHIHUN_KNOWLEDGE_0.1.1.md`만 첨부해요. 새 대화에서 버전과 관련 기준을 읽을 수 있는지 먼저 확인해요. 새 ZIP을 받는 것만으로 기존 프로젝트가 자동 갱신되지는 않아요.
