# 독립 검토 실행 안내

이 자료는 **검토 입력 준비물**이에요. 생성만으로 독립 에이전트가 실행되거나 라이팅 품질이 검증된 것은 아니에요.

## 준비

```sh
python3 scripts/build.py
python3 scripts/prepare_review.py --output /absolute/path/to/new-review-workspaces
```

생성된 역할별 폴더를 각각 별도의 새 Codex 또는 Claude Code 세션에서 열어요. 역할별 `AGENTS.md`와 `CLAUDE.md`는 같은 요청을 담아요. 이 파일이 읽혔는지와 실제 모델·호스트 버전은 실행 로그에 기록해요. 역할 이름만 바꾼 같은 대화를 독립 실행으로 세지 않아요.

## 접근 경계

작성자는 `writer/`만 읽도록 호스트의 작업 범위·권한을 설정해요. 채점자는 `grader/`와 고정된 실제 응답만 읽어요. 형제 폴더를 읽을 수 있는 환경에서는 폴더 분리만으로 정답 노출을 막았다고 주장할 수 없어요. 새 작업 하나마다 새 세션을 사용하는 것이 기본이에요.

`source-reviewer/`에는 원문 전체가 없어요. 원문 소유자가 해당 검토 작업 공간에 원문을 직접 제공해요. 원문 없이 출처 충실성 전체를 통과시키지 않아요. `engineering-reviewer/`는 결과 보고서를 받지 않는 코드 검토용 부분 자료예요. 빌드·패키징 재현에는 배포본 전체가 필요하며, 이를 제공한 경우 노출된 기존 기록을 보고서에 밝혀요.

## 실행·보고 순서

원문 검토와 공학 검토의 첫 보고서를 고정한 뒤 기존 감사와 비교해요. 작성자는 `skill/SKILL.md`와 해당 작업 입력만 읽고 답변을 저장해요. 채점자는 입력과 원문 규칙, 실제 응답, 사례별 필수·금지 의미를 비교해요. 자동 판정과 사용자의 수용 판단은 구분해요.

실행 기록에는 입력 원문과 SHA256, 실제 응답, 스킬 버전·해시, 모델·호스트 버전, 시간, 파일 읽기/수정 기록을 남겨요. 수동 예시나 모의 테스트를 실제 외부 모델 결과로 등록하지 않아요. 32개 사례는 공개된 개발용 문제이고 블라인드 시험이 아니에요.
