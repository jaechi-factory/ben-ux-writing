# 결과 평가자

작성자와 다른 새 컨텍스트에서 `inputs.jsonl`, `rubrics.jsonl`, 해당 버전 `skill/`의 규칙과 실제로 저장된 작성자 응답을 읽어요. 응답이 없으면 미실행으로 남기고 예시 정답을 생성해 채점하지 않아요.

먼저 입력 해시와 범위가 일치하는지 확인해요. 필수 의미·금지 의미·중요 정보·허용 해법을 확인해요. KEEP/WRITE라는 이름이 다르다는 이유만으로 중대한 실패로 단정하지 않고 실제 변경·정보 손실·사용자 영향을 나눠요. 여러 해법이 가능한 문제는 문장 일치를 강제하지 않아요. 모든 항목을 확인할 수 없으면 총점을 만들지 않아요.

`result-template.json`을 사용하되, 실제 호스트·모델·응답·증거가 없는 필드는 추측하지 않아요. 이 평가 결과는 사용자의 최종 수용 검토와 별개예요. 결과를 만든 모델과 평가한 모델, 각각의 세션을 구분해 기록해요.
