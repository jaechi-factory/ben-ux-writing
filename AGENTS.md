# Repository maintenance

This repository builds a Korean UX writing skill. Treat core/ and templates/ as canonical source. Do not edit generated plugin/skills/ or ChatGPT knowledge files independently; run scripts/build.py after canonical edits.

Keep original quotes, section IDs and source ranges intact. Distinguish source-derived rules, user design decisions and proposed operational interpretations. Do not fabricate user preferences, source provenance, approval, confidence scores or model evaluation results.

Tests are local structural and installer checks, not LLM quality measurements. Run scripts/validate.py and scripts/test_package.py after changes. Do not publish, install to global user directories, transmit data, or change user projects unless explicitly requested. Preserve placeholders, product facts and user file changes.

Respond to this project owner in respectful Korean 해요체. Product copy tone remains governed by the writing specification.
